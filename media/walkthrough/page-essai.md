# Page d'essai : mon premier mode opératoire

Cette page sert à essayer l'Aperçu DSFR. Rien n'est enregistré tant que vous ne le décidez pas :
modifiez, ajoutez, cassez… et regardez le résultat dans l'aperçu à droite.

/// alert | Bienvenue
    type: info
L'aperçu à droite montre cette page **comme sur le site Doc SIRH** et se met à jour pendant que vous écrivez.
///

## Insérer un composant

Placez le curseur sur la ligne vide ci-dessous, puis cliquez sur **＋ Insérer un composant** en bas de l'écran
(ou tapez `dsfr-`) et choisissez par exemple « Capture d'écran » ou « Consigne ».



## Corriger une erreur

L'alerte ci-dessous contient une faute volontaire : le mot est souligné en rouge dans l'éditeur.
Cliquez dessus, puis sur l'ampoule 💡 qui apparaît, et choisissez la correction proposée.

/// alert | À corriger
    type: warnig
Une fois corrigée, cette alerte devient orange dans l'aperçu.
///

## Replier un bloc

Une flèche apparaît dans la marge à gauche de chaque ligne `///` : cliquez dessus pour replier le bloc.
